# MyCarsHub

MyCarsHub is a full-stack peer-to-peer used-car marketplace.

## Tech Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- Socket.IO
- Razorpay

## Features

- User authentication
- Buy and sell used cars
- Car listings with images
- Search and filtering
- Saved cars
- Compare cars
- Buyer-seller chat
- Seller dashboard
- Admin dashboard
- Seller verification
- Pro subscription
- Reporting system
